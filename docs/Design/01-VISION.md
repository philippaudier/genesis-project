# Genesis Vision

Where Genesis is going. Why it matters.

---

## The Problem

Games create the illusion of living worlds, but the worlds are dead. NPCs follow scripts. Events trigger on cue. The forest fire starts when the player arrives, not because lightning struck dry wood.

Players notice. The magic breaks. The world feels hollow.

## The Cause

The standard approach models entities that act upon a passive world. This requires scripting every behavior. It cannot scale. It cannot surprise.

Worse: it inverts reality. In the real world, physics acts upon matter. Matter does not decide how physics should affect it.

## The Solution

Invert the model.

The world is active. The world has rules. The rules transform state. Entities are patterns of state. Behavior is an illusion created by transformation over time.

This is Genesis.

## What Success Looks Like

### For Developers

A framework where:
- Complex behavior emerges without being scripted
- Bugs are reproducible because the simulation is deterministic
- Systems compose cleanly because they share no hidden state
- Performance scales because rules are simple and uniform

### For Players

Worlds where:
- Actions have real consequences
- The unexpected happens (but makes sense in retrospect)
- NPCs are not obviously following scripts
- The world does not revolve around the player

### For Games

Experiences where:
- Emergent stories are the norm, not the exception
- Systemic depth replaces content volume
- Replayability comes from simulation, not from branches
- The world feels alive because it is alive

## The Ten-Year Horizon

In ten years, Genesis should be:

1. **Proven.** Multiple games shipped on Genesis.
2. **Stable.** APIs unchanged for years at a time.
3. **Understood.** Documentation complete, community knowledgeable.
4. **Referenced.** Other projects learn from Genesis's approach.
5. **Invisible.** Players don't know Genesis exists. They just know the world feels real.

## What Genesis Will Never Be

- A visual engine (Unity handles rendering)
- An AI framework (intelligence emerges from rules, not from AI)
- A content creation tool (Genesis simulates; games provide content)
- A rapid prototyping solution (Genesis favors correctness over speed)

## The First Step

Before Genesis can simulate worlds, it must establish foundations:
- A constitution that defines immutable principles
- A vocabulary that enables precise communication
- A structure that supports long-term development

This is Phase 0. This is where we are.
