# Genesis-016 — Adversarial Theory Testing

*The first milestone of the Age of Theories. The protagonist is not CT-001. The protagonist is the
method.*

## Purpose

> Determine whether CT-001 remains the best known explanation by confronting it with competing
> explanations built honestly.

The laboratory seeks neither to confirm nor to refute CT-001. It seeks to increase the explanatory
power of the corpus. Genesis-015 tested an RFC; Genesis-016 tests an *explanation* — the question is
no longer "is this primitive inevitable?" but "does this way of understanding the world still
deserve to survive?"

## The experimental rule this milestone introduces

> **Every theory on trial is entitled to an adversary built with the same intellectual honesty.**

Without an adversary, one mostly tests one's imagination. With one, one tests the world.

## Deliverables (all design; no execution)

1. At least one competing theory — **CT-002** — serious enough to produce different predictions.
2. An explanatory audit: which existing observations each candidate explains, and which neither does.
3. The strongest discriminating predictions — few, not many.
4. A pre-registered experimental campaign: worlds built, measures defined, criteria fixed — not run.
5. The possible outcomes, written before any experiment.

All five are delivered in **Campaign-001**
(`docs/Research/Campaign-001-CT001-vs-CT002.md`).

## Outcomes (fixed before any run)

- **Outcome A** — CT-001 strongly reinforced.
- **Outcome B** — CT-002 becomes preferable.
- **Outcome C** — both remain compatible → RD-1 stays open → new expedition. (Including the merger
  variant: the two turn out to be one theory at different orders of approximation.)
- **Outcome D** — both fail. → A new theory is required. This outcome protects the laboratory from
  the false dilemma "one of the two must be right." The world may answer: *you are both wrong* — and
  that is a scientific victory.

## Exit

Genesis-016 completes when Campaign-001 is fully pre-registered: both candidates' predictions filed,
worlds and measures fixed, outcome criteria bound. Execution is a separate act, authorised
separately — the design must be finished before anyone is allowed to peek.
