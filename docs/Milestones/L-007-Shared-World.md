# L-007 — Shared World

*Era II continues — and for the first time since Lootbound Lab began, nobody quite knows what will
happen. That is where the founder wanted the project to arrive.*

Status: **Prediction sealed; implementation not yet begun.** (Committed before any code — the
ancestry is the proof.)

## The scientific question

> **What does it mean to inhabit the same world?**

Not "to interact". To inhabit. Today the Traveller lives in the same world but does not yet share
it — it is almost a ghost: no need, no lasting goal, no return. It passes; it leaves.

## What is built (deliberately almost nothing)

**The Traveller returns.** Not another traveller — the same one. It may leave, and later come
back. And it finds the world as it left it: if it put a sword down, the sword is still there; if
it returns, it may take it up again. No additional AI. The same brain. Only:

```
Persistent identity.
```

Same identity, same biography, same objects. Suddenly it has continuity. It begins to have a
history. The real question is no longer "does the player meet the Traveller?" but:

> **Does the Traveller remember its own world?**

And something beautiful appears: the player is no longer the only one who returns.

## The founder's sealed prediction (filed before one line of code)

> **The first major phenomenon will probably not be an object exchange. It will be
> recognition.** Not emotional recognition — behavioural recognition. The player will say
> something like *"ah… c'est encore lui"* — with no dialogue, no name, no quest. Just a
> continuity. *(The founder: "I may be perfectly wrong. And that is fine. If this prediction
> fails, I will be delighted — it will mean the world found something we had not imagined.")*

*Scoring rule, declared now: scored on the first human run under L-007 — does behaviour or
narrative register recognition of the same other (as opposed to a new encounter, an exchange, or
something unimagined)? Never scored on scripted co-runs. The laboratory's contamination rule now
has a precedent (Run-000003): between a run and its narrative, the laboratory says nothing.*

## The tradition gains its third question (standing from this milestone on)

> **What surprised the founder?**

Surprises are now a scientific resource. The founding instances, listed at this milestone's
launch: memory compresses too · repetitions are phenomena · an absence is a first that could not
be born · presence beat the sealed expectation. They already tell a parallel story; they deserve
their own place.

## The era's guiding promise (the founder's, recorded)

> **We will never code a mechanic merely because it seems interesting. We will build it because
> it will make the world capable of producing a phenomenon it could not produce yesterday.**
