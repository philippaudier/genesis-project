*Return by another. Until today only the player came back; now the world holds a second

## The scientific question

> **What does it mean to inhabit the same world?**

Not "to interact". To inhabit. Today the Traveller lives in the same world but does not yet share
it — it is almost a ghost: no need, no lasting goal, no return. It passes; it leaves.

## What is built (deliberately almost nothing)

**The Traveller returns.** Not another traveller — the same one. It may leave, and later come
back. And it finds the world as it left it: if it put a sword down, the sword is still there; if
it returns, it may take it up again. No additional AI. The same brain. Only:

```
Persistent identity.
```

Same identity, same biography, same objects. Suddenly it has continuity. It begins to have a
history. The real question is no longer "does the player meet the Traveller?" but:

> **Does the Traveller remember its own world?**

And something beautiful appears: the player is no longer the only one who returns.
