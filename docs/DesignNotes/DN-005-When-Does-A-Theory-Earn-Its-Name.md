# DN-005 — When does a theory earn its name?

Status: **Discussion.** This note decides nothing. It poses a question the corpus has made
inevitable, and deliberately refuses to answer it before the laboratory can.

## Context

ADR-0004 recognises theories as scientific objects and rules that *a theory earns a file the day it
earns the name* — but no rule defines the moment at which an explanation stops being an ambitious
hypothesis and becomes a named theory. The corpus already contains one candidate (the spectral
stability explanation of Observations 005/007, which has survived one risky prediction) and
deliberately refuses to baptise it. Creating a Theory Register today would be an empty registry — a
violation of the vocabulary-late discipline. This note is the alternative: not the registry, but the
question of admission.

## The question

> **At what moment does a theory deserve a name?**

Not a question of prestige — a methodological one: names carry weight in this corpus (they are
earned, cited, and built upon), so the naming moment is where a free explanation acquires standing.

## First observations

A theory can probably not be named because it is elegant. Nor because it explains a single
observation. Nor because it is popular. It must have *earned* something. What?

## Candidates for the criterion (the laboratory will adjudicate)

- **A** — It explains several independent observations.
- **B** — It has survived several risky predictions.
- **C** — It has withstood an expedition explicitly designed to kill it.
- **D** — It has replaced a weaker theory.
- **E** — Some combination of the above.

## Precedent analysis (recorded, not concluded)

The question rhymes with DN-003 — *when does a pattern earn a name?* — whose settled answer was:
world-contact first (a demonstrated theorem, with ablation as its test), editorial compression
second (the Glossary rule). Under that light the candidates sort themselves: **B and C are
world-contact** (predictions are to an explanation what ablation is to a pattern); **A is
compression** (explaining several observations is compressing the corpus); **D is succession**. If
the jurisprudence holds its shape, the eventual answer will require contact and treat compression as
editorial — but that is a precedent's suggestion, not a decision. The laboratory rules.

## A subtraction: the "missing actor" is a status, not an object

Research debts do not produce theories directly; they produce **candidates**, which then face the
laboratory's tribunal. But a candidate theory is not a seventh scientific object — it is *a theory
that has not yet earned its name*: a **lifecycle stage**, exactly as observations have statuses
without being four different objects. Theories therefore carry statuses:

```
Candidate  →  Named  →  Refuted / Superseded
```

ADR-0004's ontology does not grow; it gains an axis. And this note's question becomes precise: *what
authorises the transition Candidate → Named?*

The debt-payment mechanism follows for free:

```
Research Debt → Candidate → Predictions → Expedition → Observation
```

Candidates are how debts get paid — or deepened.

## An identifier is not a name

Observation-004 has an identifier; *Source* has a name. Bookkeeping is not vocabulary. A candidate
may therefore be designated — **CT-001: the spectral stability candidate** (origin: Obs-005's λ,
Obs-007's refinement; record: one risky prediction survived, the deg-4/5 growth ratios) — without
being baptised. Designation tracks; naming honours. Only the second is rationed.

## What this note refuses

Naming a theory out of enthusiasm. Creating a register before the first named theory. Turning
theories into authorities — the laboratory will never marry a theory; it will only grant it the
right to survive until the next experiment.

## Consequences

None. This document creates no rule. It creates a scientific question — and if CT-001 one day earns
its name, it will not be because anyone found it beautiful. It will be because, despite every
attempt to kill it, the world kept agreeing with it.
