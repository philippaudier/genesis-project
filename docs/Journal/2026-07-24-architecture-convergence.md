# 2026-07-24 — The subtraction arc converges on a triad

Context: a four-step adversarial arc, all in Research, all with the Constitution and RFC-0001 left
untouched. Each step *removed* a layer rather than adding one:

1. `Transformation-Model.md` — proposed Intent → Validation → Transformation → World.
2. `Transformation-Model-Critique.md` — Intent survives but over-claims universality (W1 field grain,
   W2 emergent origin, W3 validation overload).
3. `Producers-Hypothesis-Critique.md` — "two producers (Agent/Rule)" is the wrong number; likely one
   producing mechanism, plus a constraint layer the producer framing cannot see.
4. `Minimal-Architecture-Critique.md` — the minimal "Interfaces → State → Rules → New State" is a
   discrete dynamical system rediscovered. "Rule" is not a primitive; it factors the transition
   function.

**Provisional resting point (NOT a decision):** the conceptual bedrock of Genesis appears to be a
**constrained dynamical system over explicit state, observed from outside**:

```
External boundary  →  [ State  ·  Transition (Rules)  ·  Constraint ]  →  next State
```

- Three irreducible internal elements. None collapses into another: State ≠ Transition (Article V
  keeps verb distinct from noun); Transition ≠ State (something must interpret rule-data as change);
  Constraint ≠ Transition (a predicate forbids, it does not produce).
- One external boundary (input u(t) + initial condition x(0)) where Interfaces attach — the same line
  the Constitution already drew in Articles II and XI.

**Why stop subtracting here (by the creator's own test):** removing Intent/Agent/Producer/Rule-as-
primitive lost no explanatory power. Removing **Constraint as distinct from Rule does** — invariants
would have to be decentralised into every rule (unenforceable) or reintroduce a validation phase
(un-removing the layer). That is the fold that must be refused.

**Open, deliberately unresolved:**
- W1 (continuous-field grain / conservation-solving) was never addressed by any collapse — it is
  orthogonal to origin and still open.
- The producer/validator (transition/constraint) division of labour is unspecified.
- Whether this triad should be written up as an RFC, or surfaced as a confirmation that the
  Constitution already implied it (Articles V, VII, XI, XII), is not decided.

Nothing here is enshrined as project fact yet. When/if adopted, it graduates from Research into an
RFC — and only then into memory.
