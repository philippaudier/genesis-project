## Derived behavioural observation

```
Six of ten narratives treat the runs as one continuing world: return, custom, comparison,
concealment-from-future-perception. The subject's memory persists; the world's does not.
Every one of those narrated phenomena — habit, being-noticed, "as before" — is currently
FICTION: the narrator is living in a world the simulation does not provide.
```

## Unexpected phenomenon

```
The demand for persistence arrived from narratives, not from design. RFC-L003 — Persistent
History — was founded on day one and deferred until a world demanded it. The demand-side
document now exists, and it is written in the founder's own run files: the player is
already living in the persistent world; only the world disagrees. Also unimagined: the
instrument's vocabulary colonised the narrator (the display's labels became the subject's
words) — the Faithful Window shapes not only what can be experienced but how it is told.
```

## What the laboratory does not know

```

  maintained).
- What would change in the narratives if the world actually persisted — the reverse is
  now testable.
```

## Alternative explanations (preserved, none privileged)

```
A1  Humans narrate continuity wherever identity repeats; the deterministic Traveller makes

A3  Continuity lives in the only place it truly exists — the narrator — and the narratives
    are accurate reports of THAT world, not this one.
```
