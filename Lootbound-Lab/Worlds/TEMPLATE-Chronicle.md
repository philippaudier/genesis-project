# World-NNN — Chronicle

*A new document type, founded at Genesis II's opening: not a laboratory journal, not an
observation, not an RFC — the journal of one particular world. Worlds now have biographies; this
is where one is kept. Updated by visits, never rewritten.*

```
Birth
Age                (sessions · ticks)
Known inhabitants
Major events
Objects still missing
Firsts
Lasts
```

*A chronicle ends only one way: the ceremony. When its world is abandoned, the chronicle closes
with the word — Abandoned — and stays on the shelf forever, like a finished book.*

> **A world is not finished when nothing more can happen.
> It is finished when nobody will ever live there again.**
> *(the founder, 2026-07-28, upon closing the first book — living beside "No hidden hand" and
> "The world has asked")*
